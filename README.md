# JBL110 Innovation & Regulation – Repository Guide

A compact guide to what’s in this repo and where to find generated summaries and exams.

## What this is
A knowledge base for the JBL110 course (Innovation & Regulation). Source content is Markdown; lecture slides are PDFs.

## Folder overview
- `Module_1/` … `Module_5/`
  - Lecture notes and mandatory readings per module.
  - Each module may include a `Generated/` subfolder for AI-created aids (summaries, outlines, answers).
- `Lecture_Pdfs/Module_1/` … `Lecture_Pdfs/Module_5/`
  - PDF versions of lecture slides. (Also contains comprehensive summaries in pdf format)
- `Exams/`
  - Mock exams and materials: e.g., `Mock_Exam_1.md`, `Mock_Exam_1_Answers.md`, `Guide to solving problem questions.md`, `JBL 110 Exam July 2025.md`.
  - Generated practice exams and answers live in `Exams/Generated/` (e.g., `Exams/Generated/Generated_Exam_2025_10_31.md`).
- `Quizzes/`
  - Past quiz assignments and rationales.
- `Generated/` (root)
  - Cross-module, holistic summaries (see below for contents).
